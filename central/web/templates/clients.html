Add client

A client is a Sentinel installation. Use a local path or an SMB URL such as smb://192.168.0.164/sentinel/packet.db. Packet-cache settings are written to central-cache.json next to that database so the sensor can apply them.

Same source MAC + SSID + vendor + device type is stored at most once per window. Central writes central-cache.json next to packet.db when the share is writable. If Samba is read-only, put central-url.txt beside packet.db with the Central URL (for example http://192.168.0.10:8093) and restart Sentinel on the Pi.
